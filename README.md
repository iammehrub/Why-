# WHY? — Human Behavior + Science Shorts

Daily original YouTube Shorts about human behavior, psychology, brain science, and everyday science.

GitHub Actions runs daily at 17:00 UTC. It researches a topic, generates a source-grounded 45–60 second script, creates narration, adds visuals, renders the Short, and uploads it.

Required secrets: OPENAI_API_KEY, PEXELS_API_KEY, YOUTUBE_CLIENT_ID, YOUTUBE_CLIENT_SECRET, YOUTUBE_REFRESH_TOKEN.

No artificial views, likes, comments, or subscribers are generated.
